# Hosted closed test (Render + Neon, free tiers)

Purpose: let friends install an Android APK and play over the internet before
the store launch. This is a **closed test**, not the production setup.

## Pieces
- **Game server**: Render free web service from `render.yaml` (Frankfurt).
  WebSockets work on Render. The free instance sleeps after ~15 minutes idle,
  so the first open afterwards takes about a minute; live rooms are lost when
  it sleeps or redeploys.
- **Database**: Neon free Postgres (does not expire, unlike Render's free DB).
  Use the *direct* connection string (pooling off) because `prisma migrate
  deploy` runs at every start.
- **Sign-in**: Google/Apple are not configured yet, so the server enables
  `POST /auth/tester` when `CLOSED_TEST_CODE` is set (6+ chars). The app,
  built with `TESTER_SIGN_IN=true`, asks for the invite code once and keeps a
  random device key in secure storage; the server stores only its SHA-256.
  Uninstalling the app loses that account. 10 wrong codes per IP lock out for
  10 minutes. Dev sign-in stays off (`NODE_ENV=production`).
- **Content**: `SEED_APPROVED_CONTENT=1` loads the AI-drafted questions and spy
  packs as approved at each start (idempotent). They still need human review
  before a public release; set it to `0` once content goes through the admin
  panel.

## Setup
1. Neon: create a project (region Frankfurt), copy the connection string with
   pooling off.
2. Render: New > Blueprint > this repository, branch
   `feat/foundation-and-quiz-slice`. Enter `DATABASE_URL` (from Neon) and
   `CLOSED_TEST_CODE`. `JWT_SECRET` is generated by Render.
3. Check `https://<service>.onrender.com/health`.
4. Build the APK:
   ```
   flutter build apk --release \
     --dart-define=SERVER_URL=https://<service>.onrender.com \
     --dart-define=TESTER_SIGN_IN=true
   ```
   Release builds are signed with the debug key for now (fine for sideloading,
   not for Play). iPhone friends cannot install an APK.

## Alternative without a card: this PC + ngrok

Render asks for a card even on the free plan. Without one, run the server on
the owner's PC and expose it through a free ngrok static domain (works only
while the PC and the server are running):
1. Create an ngrok account, run `ngrok config add-authtoken <token>` once, and
   copy the free static domain from the ngrok dashboard (Domains).
2. Start: `powershell -ExecutionPolicy Bypass -File apps\server\scripts\start-public.ps1 -Domain <domain>`
   (asks for the invite code; turns dev sign-in off).
3. Build the APK with `--dart-define=SERVER_URL=https://<domain>`.
